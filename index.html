ℹ️ How Browser Storage Works

SmartAttend AI stores data in your browser's localStorage under clear keys (smartAttend_students, smartAttend_classes, smartAttend_attendance, smartAttend_sessions, smartAttend_settings). Data persists across page refreshes on this device, but clearing browser site data will erase it. It is designed for offline-friendly classroom demos, not as a production cloud database.
